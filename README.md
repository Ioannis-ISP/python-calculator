# Python Calculator

My first Python project, created while learning Python programming.

## About

This is a command-line calculator that allows users to perform multiple calculations in one session.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Supports decimal numbers
- Handles invalid number input
- Prevents division by zero
- Allows multiple calculations until the user enters `=`

## What I Learned

While building this project, I practiced:

- Variables and user input
- `while` loops
- Conditional statements (`if`, `elif`, `else`)
- Exception handling (`try` and `except`)
- Arithmetic operations
- Input validation
